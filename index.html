FEATURE ENGINEERING

特徵選擇方法矩陣 (Feature Selection Matrix)

要求學生在僅使用訓練集 (Training Data) 的嚴格防洩漏條件下，比較挑選 14、20、25 或 30 個特徵之效果。

Filter Method (過濾法)

SelectKBest (f_regression / mutual_info)

透過單變量統計檢定（如 F 檢定或互資訊量），計算每個特徵與目標變數的相關強度，選取前 k 個最高分者。

運算速度： 極快 (適合高維度初步篩選)
缺點： 忽略特徵之間的複合交互作用與共線性
from sklearn.feature_selection import SelectKBest, f_regression
selector = SelectKBest(score_func=f_regression, k=20)
X_train_selected = selector.fit_transform(X_train, y_train)
Wrapper Method (包裝法)

RFE (遞迴特徵消除法)

反覆訓練回歸模型，每次淘汰權重係數絕對值最小的特徵，遞迴修剪直到剩下指定的特徵數。

優勢： 考慮特徵與估計器的共變影響
缺點： 需多次重新訓練模型，運算量隨維度增加
from sklearn.feature_selection import RFE
from sklearn.linear_model import LinearRegression
rfe = RFE(estimator=LinearRegression(), n_features_to_select=20)
X_train_rfe = rfe.fit_transform(X_train, y_train)
Wrapper Method (包裝法)

Sequential Feature Selection (SFS)

序列式貪婪演算法（可選前向 Forward 或後向 Backward），基於交叉驗證分數逐步加入或剔除特徵。

優勢： 評估指標直接對齊交叉驗證 $R^2$ 或負 MSE
缺點： 容易陷入局部最優解，計算成本較高
from sklearn.feature_selection import SequentialFeatureSelector
sfs = SequentialFeatureSelector(LinearRegression(), n_features_to_select=20, direction='forward', cv=5)
X_train_sfs = sfs.fit_transform(X_train, y_train)
Embedded Method (嵌入法)

Lasso L1 正則化稀疏性

利用 L1 懲罰項將不重要或冗餘特徵的回歸係數直接壓縮至 0，自然達到特徵自動淘汰。

優勢： 訓練模型與特徵選擇同步完成，防止過擬合
調參重點： 需透過 LassoCV 尋找最佳正則化懲罰 $\alpha$
from sklearn.linear_model import LassoCV
lasso = LassoCV(cv=5).fit(X_train, y_train)
selected_mask = (lasso.coef_ != 0)
selected_features = X_train.columns[selected_mask]
Model-Agnostic (模型無關檢驗)

Permutation Importance (排列重要性)

將某一特徵欄位的值隨機打亂（打斷其與目標變數的關聯），觀察模型評估指標（如 $R^2$ 或 MSE）下降的劇烈程度。下降越多代表該特徵越關鍵。

核心特質： 直觀可靠，且能在驗證集上客觀檢測是否真正對泛化能力產生貢獻。
from sklearn.inspection import permutation_importance
perm = permutation_importance(model, X_train, y_train, n_repeats=10, random_state=42)
top_k_indices = perm.importances_mean.argsort()[::-1][:20]
THEORETICAL RIGOR

五大多元線性回歸假設檢定 (The 5 Assumptions)

在專案作業中，評估模型時必須檢視並回答以下五大假設是否滿足：

假設 1

線性關係 (Linearity)

自變數 $X$ 與因變數 $Y$ 之間必須具備實質的線性關聯性。

診斷手法： 繪製各特徵與 Target 之散佈圖、檢視殘差對預測值散佈圖 (Residuals vs Fitted Plot)。若呈現拋物線形狀則需進行多項式特徵轉換。
假設 2

殘差獨立性 (Independence)

各觀測樣本之殘差 $\epsilon_i$ 互相獨立，不存在自相關 (Autocorrelation)。

診斷手法： 計算 Durbin-Watson 統計量 (數值介於 0~4，約等於 2 代表無自相關；顯著小於 2 代表正自相關)。
假設 3

同質變異性 (Homoscedasticity)

所有預測值水平下，殘差之變異數皆保持恆定 $\text{Var}(\epsilon_i) = \sigma^2$。

診斷手法： 檢查殘差對預測值圖（漏斗形狀即代表異質變異）、執行 Breusch-Pagan 檢定 或 White 檢定。
假設 4

殘差常態性 (Normality)

回歸誤差項 $\epsilon$ 服從常態分佈 $\epsilon \sim N(0, \sigma^2)$。

診斷手法： 繪製 Q-Q Plot (分位數對照圖) 與殘差直方圖 KDE、執行 Shapiro-Wilk 檢定 或 Jarque-Bera 檢定。
假設 5

無多重共線性 (No Severe Multicollinearity)

自變數之間不得存在過度強烈之線性相依關係，否則會導致回歸係數標準誤膨脹、正負號逆轉。

診斷與處置手法： 計算 變異數膨脹因子 VIF (Variance Inflation Factor)。 一般準則：$\text{VIF} < 5$ 屬良好，$\text{VIF} > 10$ 代表存在嚴重多重共線性。 處置方式包含：剔除高 VIF 特徵、改用 Ridge (L2 脊回歸) 或透過 PCA 降維。
